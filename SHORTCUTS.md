# NinjaSight Pro — keyboard and mouse reference

All shortcuts can be changed in Settings › Shortcuts.

## Viewer

| Key | Action |
|---|---|
| → / PageDown | Next image |
| ← / PageUp | Previous image |
| Home / End | First / last image in the folder |
| Esc | Close viewer (or cancel the current action / dialog) |
| F / F11 | Toggle fullscreen |
| + / - | Zoom in / out |
| 0 | Fit image to window |
| 1 | Display at 100% |
| R / Shift+R | Rotate clockwise / counterclockwise |
| E | Enter / leave annotation mode |
| Ctrl+R | Resize panel |
| Ctrl+B | Batch processor |
| Ctrl+E | Export |
| Ctrl+Shift+P | Print |
| Ctrl+F | Find duplicates |
| Ctrl+Shift+X | Screenshot (also system-wide) |
| Ctrl+S / Ctrl+Shift+S | Save project / Save project as |
| Ctrl+O / Ctrl+Shift+O / Ctrl+P | Open file / folder / project |
| Ctrl+N | Open in a new window |
| Space | Hide / show toolbars |
| I | Information overlay |
| T | Thumbnail strip |
| B | Image browser |
| Ctrl+← / Ctrl+→ | Previous / next frame of an image sequence |
| Ctrl+, | Settings |
| F1 | This reference |

## Annotation mode

| Key | Action |
|---|---|
| V T C P H L A D N B X | Select, Text, Callout, Pen, Highlighter, Line, Arrow, Double arrow, Marker, Blur, Pixelate |
| Ctrl+Z / Ctrl+Y | Undo / redo |
| Delete | Delete selected annotation |
| Ctrl+D | Duplicate |
| Ctrl+C / Ctrl+V | Copy / paste annotations |
| Ctrl+A | Select all |
| Ctrl+G / Ctrl+Shift+G | Group / ungroup |
| Ctrl+] / Ctrl+[ | Bring forward / send backward |
| Arrow keys | Nudge selection (Shift = 10 px) |
| O | Objects panel |
| Esc | Finish text · deselect · back to Select tool · leave annotation mode |

## Mouse

| Mouse | Action |
|---|---|
| Wheel | Zoom around the cursor |
| Left drag | Pan when zoomed in (moves the window when the picture fits) |
| Middle drag | Pan |
| Double-click | Fullscreen · edit text in annotation mode |
| Right-click | Context menu |
| Shift while drawing | Square / circle, 15° angles, keep proportions |
| Ctrl+drag (any tool) | Move an existing annotation |
| Ctrl while rotating | Rotation handle, end of a line / arrow, Angle field: 15° steps |
| Clone properties, Ctrl+click | Give the copied properties to several objects (Esc stops) |
| Vectorized pen, Alt+drag a handle | Corner point (the two handles move separately) |
| Wheel over the thumbnail strip | Previous / next picture (carousel) |
| Wheel / drag in the duplicates comparison grid | Zoom / move every picture together |
| Window edges | Resize the window (when not maximized) |
